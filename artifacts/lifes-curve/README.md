# Life’s Curve — Manisha’s Cosmic Academy

Premium single-page website for Life’s Curve by Manisha.

## Open locally

Open `index.html` in a modern browser, or from this folder run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Contents

- Course-first hero and Cosmic Academy cards
- About Manisha
- Why learn / curiosity path
- Secondary consultations
- Testimonials with drag scroll
- Contact placeholders for WhatsApp, phone and email
- Continuous Life Curve line tied to scroll

Course names, durations and prices match the supplied brief.
